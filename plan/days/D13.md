# D13. 고른 문맥을 JSON으로 복사한다

- 이어받은 일:

D02가 끝난 뒤에 이 날의 복사 버튼을 미리 만들어도 된다. 완료 데모는 페이지 선택이 있는 현재 화면에서 한다.

## 오늘 끝나야 보이는 것

`문맥 복사`를 누르면 클립보드에 문맥 JSON이 들어간다. 문서 전체 모드에서는 문단 `node_id` 목록이 들어가고, 문서는 수정되지 않는다.

## 데모 순서

1. 문단 일부를 드래그한다.
2. `문맥 복사`를 누른다.
3. 붙여 넣은 JSON에 `node_id`, `selected_text`, `text_range`, 앞 문단, 다음 문단이 있다.
4. 문서 전체 모드를 켜고 다시 복사한다.
5. `node_ids` 길이가 문단 수와 같다.
6. 복사 전후 문단 텍스트가 같다.

## 혼자 할 때

B의 `buildContext` 테스트를 고정하고 A의 버튼에 연결한다.

## 나눠 할 때

- B: `packages/commands의 context 빌더만 추가한다. 모델 SDK를 넣지 않는다.`
- A: `복사 버튼과 문서 전체 토글만 추가한다.`

## 트랙 B — 문맥 (필수)

### WBS

1. [연결 경계](../04-연결-경계.md)의 문맥 JSON을 만드는 `buildContext`를 구현한다.
2. 앞뒤 문단이 없으면 빈 문자열을 넣는다.
3. 문서 모드는 문단 id 배열만 넣고 명령은 만들지 않는다.
4. 함수가 입력을 수정하지 않는 테스트를 둔다.

### 테스트

- 선택 필드가 입력과 같다
- 문서 모드의 id 개수가 문단 수와 같다
- 호출 전후 원문 배열이 같다

### 완료

- [ ] 테스트 통과

## 트랙 A — 화면 (필수)

### WBS

1. `문맥 복사` 버튼을 선택 패널에 둔다.
2. 클립보드 쓰기가 실패하면 JSON을 화면에 펼쳐 수동 복사가 되게 한다.
3. `이 문서 전체` 토글을 둔다.
4. 토글이 켜져도 기존 문단에 명령을 자동 생성하지 않는다.

### 완료

- [ ] 데모 1–6

## 막히면
