# WP-05. 각주가 있는 파일의 본문만 고친다

- 상태: 시작 전
- 크기: 하루
- 착수: D09 성공과 D15의 저장 가드
- 디렉터리: `packages/hwpx`

## 오늘 끝나야 보이는 것

각주가 있는 문서를 열면 각주 표시가 본문과 구분된다. 각주 본문을 텍스트 명령으로 고치는 버튼은 없다. 본문 문단만 수정한 결과에서 각주 참조가 남아 있으면 한컴에서 연다. 참조가 떨어지면 저장을 막는다.

## WBS

1. 로컬 T06을 만든다. 본문 한 줄, 각주 한 개.
2. 모델이 각주 참조를 별도 `kind: note`로 반환하는지 테스트한다.
3. `note`에는 `replace_text`를 거절한다. 코드는 `NOT_A_TEXT_TARGET`이다.
4. 본문 패치 후 참조 ID가 원본과 같은지 비교한다.
5. 한컴에서 각주 번호가 보이는지 기록한다.

## 테스트

- 각주 대상 명령 거절
- 참조 ID 유지
- 유지 실패 시 저장 바이트 없음
