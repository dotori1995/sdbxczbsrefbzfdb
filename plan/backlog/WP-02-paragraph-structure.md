# WP-02. 문단을 넣거나 빼면 한컴에서 열린다

- 상태: 시작 전
- 크기: 하루. 한컴 확인이 실패하면 그 날은 실패 기록으로 닫고 기능을 기본 비활성으로 남긴다.
- 착수: D09 성공
- 디렉터리: `packages/hwpx`, 버튼만 `apps/web`

## 오늘 끝나야 보이는 것

단일 런 문단 뒤에 문단 하나를 넣는 명령과, 단일 런 문단을 빼는 명령이 승인 흐름을 탄다. 결과 파일이 한컴에서 열린다.

## 요구

- 명령 이름은 `insert_paragraph`, `delete_paragraph`다.
- 혼합 런 문단 삭제는 거절한다.
- 더미 요소가 있는 문단 삭제는 `UNVERIFIED_PART`로 거절한다.
- 삽입 문단은 이웃 문단의 문단 속성 중 검증된 최소만 복사한다. 복사 범위를 메모에 적는다.

## WBS

1. 두 명령을 스키마에 추가한다.
2. fixture에서 삽입 후 문단 수가 1 늘고, 삭제 후 1 줄어드는 테스트를 둔다.
3. 비대상 엔트리 해시를 유지한다.
4. 화면에 명령 결과를 반영한다.
5. 한컴 열기 결과를 `notes/hancom/WP02.md`에 적는다.
6. 한컴이 실패하면 버튼을 숨기고 테스트에 `skip` 대신 거절 기본값을 둔다.

## 테스트

- 삽입과 삭제 fixture
- 혼합 런 삭제 거절
- 한컴 기록
