# WP-03. 스타일 명령은 조건을 정하기 전에는 거절한다

- 상태: 시작 전
- 크기: 하루
- 착수: D04 이후
- 디렉터리: `packages/commands`, `notes/engines`

이 카드의 완료는 스타일 적용이 구현된 상태가 아니다. 적용을 막는 조건이 테스트로 고정된 상태다.

## 오늘 끝나야 보이는 것

`set_character_style` 또는 `set_paragraph_style` JSON을 붙여 넣으면 `STYLE_HOLD`가 보이고 저장 버튼이 꺼진다.

## WBS

1. 두 이름을 알 수 없는 명령과 구분해 거절 코드를 `STYLE_HOLD`로 반환한다.
2. 화면에 `스타일 변경은 참조 검증 전이라 막혀 있습니다`를 보인다.
3. `notes/style-hold.md`에 나중에 허용하려면 확인할 항목을 적는다.
   - 스타일 ID가 header에 존재하는지
   - 사용하지 않는 ID를 지우는 경로가 없는지
   - 문자 속성만 바꿀 때 문단 속성이 유지되는지
   - 한컴 재저장 후 ID가 유지되는지
4. 스타일 XML을 수정하는 코드를 넣지 않는다.

## 테스트

- 두 명령이 `STYLE_HOLD`다
- T01 텍스트 수정 회귀가 통과한다

## 완료

- [ ] 테스트
- [ ] 메모
- [ ] 스타일 쓰기 함수가 없다
