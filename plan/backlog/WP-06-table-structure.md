# WP-06. 표에 행을 하나 넣는다

- 상태: 시작 전
- 크기: 하루. 한컴 실패 시 기능을 끈다.
- 착수: D08과 D09 성공
- 디렉터리: `packages/hwpx`의 표 패치, `apps/web`의 행 버튼

병합된 칸이 있는 표는 대상에서 제외한다.

## 오늘 끝나야 보이는 것

2행 2열의 단순 표에서 `행 추가`를 승인하면 빈 칸 두 개가 더 보이고, 받은 파일이 한컴에서 열린다. 기존 칸의 문장은 그대로다.

## WBS

1. `insert_table_row`를 스키마에 추가한다.
2. 병합 속성이나 열 개수가 불규칙하면 `TABLE_HOLD`로 거절한다.
3. 단순 표 fixture에서 행 수가 1 증가하는 테스트를 둔다.
4. 기존 칸 텍스트를 비교한다.
5. 화면에 새 행이 보인다.
6. 한컴 결과를 `notes/hancom/WP06.md`에 적는다.
7. 실패하면 명령을 `TABLE_HOLD` 기본값으로 되돌린다.

## 테스트

- 단순 표 행 증가
- 병합 표 거절
- 기존 칸 텍스트 유지
