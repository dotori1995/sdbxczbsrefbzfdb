# WP-00. 라이선스 실사

- 상태: 시작 전
- 크기: 하루
- 착수: 아무 때나
- 완료가 필요한 시점: 저장소 밖 배포, 상용 포함, 의존성 고정 전
- 디렉터리: `notes/engines`만

## 오늘 끝나야 보이는 것

화면에 기능을 추가하지 않는다. `notes/engines/license.md`에 후보별 결론이 `사용 가능`, `조건 필요`, `보류` 중 하나로 적힌다.

## 대상

- edwardkim/rhwp
- airmang/python-hwpx
- 앱에 실제로 들어간 npm 의존성

fork를 보면 upstream과 차이를 한 줄로 적는다. 코드를 복사해 오지 않는다.

## WBS

1. 각 저장소의 LICENSE 종류와 저작권 표시를 적는다.
2. `package.json` 또는 `Cargo.toml`, `pyproject.toml`의 직접 의존성 라이선스를 표로 적는다.
3. 샘플 파일과 폰트를 재배포하는지 확인한다. 재배포하면 그 라이선스를 적는다.
4. copyleft가 앱 전체에 붙는 조건이 있는지 적는다.
5. 법률 검토가 필요한 항목은 `검토 필요`로 남기고 결론을 단정하지 않는다.
6. 앱 의존성에 아직 없는 라이브러리를 이 작업 중에 추가하지 않는다.

## 테스트

- 표의 저장소 URL을 다시 열어 LICENSE 파일이 메모와 같은지 확인한다.
- `pnpm licenses list` 또는 그에 해당하는 출력을 메모에 첨부한다.
