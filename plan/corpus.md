# 코퍼스

자동 테스트용 최소 패키지는 한컴 없이 `packages/hwpx` 테스트가 ZIP으로 만든다. 한컴 확인용 파일은 로컬 `corpus/hancom/`에 둔다.

## 샘플

| ID | 문서 | 쓰는 날 | 자동 fixture | 한컴 파일 |
|---|---|---|---|---|
| T01 | 문단 둘. 서식 없음 | D01부터 | 필수 | D09 필수 |
| T02 | 한 문단 안에 굵게와 일반이 같이 있음 | D04 | 필수. 적용 거절 확인 | 저장 시도 안 함 |
| T03 | 2행 2열 표. 칸마다 문장 하나 | D08 | 필수 | D09 이후에 같은 절차 |
| T04 | 문단 하나와 이미지 하나 | D12 | BinData가 있는 ZIP | 보존 확인 |
| T05 | 머리말 또는 꼬리말 | 백로그 | 편집 차단 확인용 | 수정 저장 안 함 |
| T06 | 각주 또는 미주 | 백로그 | 편집 차단 확인용 | 수정 저장 안 함 |
| T07 | 수식 또는 차트 | 백로그 | 요소가 결과에 남는지 | 수정 저장 안 함 |
| T08 | 다단 | 백로그 | 표시 한계를 기록 | 수정 저장 안 함 |
| T09 | 문단, 표, 이미지가 같이 있음 | D12 | 문단만 바꾼 뒤 나머지 엔트리 비교 | D09 통과 후 |
| T10 | 한컴에서 저장한 파일을 다시 파싱 | D09 | 한컴 결과물이 있을 때 | 필수 |
| T11 | 같은 문장이 두 문단에 반복 | D10 | 필수 | 선택 |

## 만드는 방법

T01 한컴 파일은 한글에서 새 문서를 만들고 문단을 두 개 입력한 뒤 HWPX로 저장한다. 본문은 공개해도 되는 문장만 쓴다. 예: `첫번째 문단이다.` / `두번째 문단이다.`

파일 이름: `corpus/hancom/T01.hwpx`

## 인벤토리

D02의 트랙 C가 `tools/corpus/inventory`를 만든다. 출력은 엔트리 경로, 압축 방식, 압축 크기, 원본 크기, SHA-256이다. 본문은 출력하지 않는다.

D06부터 패치 전후 인벤토리를 비교한다. 변경 허용 엔트리 외의 해시가 다르면 테스트가 실패한다.

## 커밋

- 테스트가 생성하고 버리는 fixture는 커밋하지 않아도 된다.
- 재현에 필요한 최소 XML 조각은 테스트 소스에 둔다.
- `corpus/hancom/`은 gitignore한다. README에 파일 이름과 만든 한글 버전만 적는다.
