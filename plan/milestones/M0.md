# M0. 고르고 미리본다

D01, D02, D03.

## 목표

HWPX를 올리면 글이 보이고, 문단을 고른 뒤 바꿀 문장을 적으면 명령 초안이 만들어지고, 승인 전에는 원문이 그대로다.

## 요구사항

R-VIS-01, R-VIS-02, R-SEL-01, R-CMD-01, R-CMD-02, R-CMD-03, R-CMD-05.

## 완료 조건

- 데모: 업로드 → 문단 클릭 → 바꿀 문장 입력 → 검증 통과 → 나란히 비교 → 거절 또는 미승인 상태에서 다운로드 버튼 없음.
- `pnpm test` 통과.
- 받은 파일의 바이트와 화면의 원문 텍스트가 승인 없이 변하지 않는다.
- 트랙 D 메모가 있든 없든 화면 스택은 유지된다. 시간상자를 넘긴 항목은 기록만 있으면 된다.

## 테스트

자동: fixture ZIP 문단 추출, 허용 명령 검증, 원문 불일치 거절, 혼합 런 판정은 D04에서 닫는다.

수동: 하루 파일의 데모 순서.

## 병렬

D01부터 A와 B를 동시에 열 수 있다. C와 D는 시간상자다. D02가 끝나면 D05와 D13을 미리 열 수 있다. M0 완료를 그 작업의 전제로 두지 않는다.

## 이 마일스톤의 범위 밖

XML 패치, 파일 다운로드, 페이지 조판, 모델 호출.
