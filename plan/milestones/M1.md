# M1. 승인하면 파일로 남는다

D04, D06, D07, D08, D09. 달력에서는 D05가 D04와 D06 사이에 있다. D05는 [M2](M2.md)다.

## 목표

승인한 명령이 단일 텍스트 런의 문단 또는 표 칸만 바꾸고, 나머지 엔트리는 원본 바이트로 남고, 새 HWPX가 내려받아지며, T01이 한컴 한글에서 열리고 다시 저장된다.

## 요구사항

R-CMD-06, R-CMD-07, R-PKG-01, R-PKG-02, R-PKG-03, R-PKG-05, R-VIS-04, R-SEL-03, R-HAN-01, R-HAN-02, R-HAN-03.

## 완료 조건

- 단일 런 문단의 `replace_text` 결과가 화면과 결과 ZIP의 해당 텍스트에 같이 반영된다.
- 다른 문단의 원문과, 변경 대상이 아닌 엔트리의 SHA-256이 같다.
- T02 혼합 런은 적용이 거절되고 결과 파일이 만들어지지 않는다.
- 다운로드는 새 파일이다. 원본 경로는 바뀌지 않는다.
- `notes/hancom/D09-T01.md`에 한글 버전, 열기, 저장, 다시 열기 결과가 있다.
- 한컴 단계가 실패하면 마일스톤을 완료로 적지 않는다.

## 테스트

자동: 패치 전후 해시, 혼합 런 거절, 표 칸 하나 변경, `mimetype`이 압축되지 않는지.

수동: 결과 파일을 한컴에서 연다. 절차는 [D09](../days/D09.md).

## 병렬

D04의 화면 적용과 D06의 바이트 패치는 B 안에서도 모듈을 나눈다. `packages/hwpx/src/model`과 `packages/hwpx/src/patch`. A는 model만 먼저 사용한다.

D09 실패 중에는 A의 신규 화면을 머지하지 않는다.

## 이 마일스톤의 범위 밖

글자 단위 드래그, 이미지 편집, 스타일 변경, 모델 호출.
