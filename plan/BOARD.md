## 같은 날에 나눌 수 있는 쌍

의존이 끝나는 순간부터 다음 날을 기다리지 않고 열 수 있다.

| 먼저 끝날 것 | 이어서 동시에 열 수 있는 것 | 이유 |
|---|---|---|
| D02의 `node_id`와 선택 JSON | D05 SVG 줄 배치, D13 문맥 복사 | 둘 다 선택을 읽기만 한다 |
| D03 미리보기 상태 | D04 메모리 적용, D05 페이지 | A는 페이지, B는 적용. 디렉터리가 다르다 |
| D04 단일 런 규칙 | D06 XML 패치 | 화면 적용과 바이트 패치를 분리한다 |
| D07 다운로드 | D12 이미지 보존 검사 | 저장 경로가 생긴 뒤의 회귀다 |
| D08 표 선택 | D10 글자 드래그 | 선택 종류가 다르다. 히트 테스트 파일만 겹치지 않게 나눈다 |
| D02 검증기 | D14 붙여넣기 UI의 자리 | 붙여넣기 완료는 D07 적용이 있어야 데모가 닫힌다. UI 자리는 D02 다음부터 만들어도 된다 |

D09가 실패하면 D10, D11, D12의 신규 표시 작업을 열지 않는다.
