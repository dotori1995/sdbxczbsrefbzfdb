# 뷰어

화면의 문서는 우리가 만든 SVG다. 첫날부터 `<svg>` 안에 문단을 그린다. HTML 목록이나 Canvas로 문서를 대신 그리지 않는다.

선택, 승인, 명령 패널은 SVG 밖의 HTML이다. SVG를 다시 HWPX로 바꾸지 않는다. 패치가 읽는 값은 `node_id`와 원문이다.

## rhwp에서 보는 것

[edwardkim/rhwp](https://github.com/edwardkim/rhwp)는 참고 문서다. 의존성으로 넣지 않고, 저장소를 포크하거나 WASM을 빌드하지 않는다.

메모할 때 볼 범위는 README의 렌더링과 SVG 출력 설명까지다.

- 페이지 한 장당 그림 하나를 둔다.
- 글자, 문단, 표 칸, 이미지를 좌표가 있는 요소로 나눈다.
- 선택 표시는 본문 요소와 분리한다.

그 세 가지를 우리 SVG에 적용한다. paint IR, CanvasKit, `@rhwp/editor`, hwpctl, HWP 바이너리 파서는 가져오지 않는다. 코드 조각을 복사하지 않는다.

## 우리 SVG

| 요소 | 표시 | 식별 |
|---|---|---|
| 페이지 | `<svg>` 한 장. 너비는 A4에 해당하는 794px | `data-page` |
| 문단 | `<text>` | `data-node-id` |
| 줄 | 같은 문단의 `<text>` 여러 개 | `data-node-id`와 `data-line` |
| 표 칸 | `<rect>`와 그 안의 `<text>` | 칸 `data-node-id` |
| 이미지 | `<image>` 또는 경고 `<rect>` | `data-node-id` |
| 선택 | 본문 그룹 위의 `<rect>` | 원문 텍스트를 바꾸지 않음 |

D01은 문단마다 `<text>` 하나를 세로로 쌓는다. 그날의 화면은 글꼴 크기와 자간을 그리지 않는다. 그 값은 `header.xml`의 글자 모양에 있으므로, 화면은 시스템 한글 폰트를 쓰고 모델은 D01부터 `paraPrIDRef`와 `charPrIDRef`를 갖고 있는다. D05에서 페이지 높이와 줄 나눔을 넣는다. 그날의 줄은 16px/8px, 너비 710px 근사치다. 그 차이는 `notes/layout-gaps.md`에 적고 SVG는 유지한다. 한컴과 줄바꿈이 같다고 두지 않는다. 한컴과 같은 조판이 끝났다고 두지 않는다.

승인한 서식은 화면에 바뀌어 보여야 한다. 글자 크기와 글자색, 문단 정렬, 쪽 여백은 [WP-03](backlog/WP-03-style.md)에서 SVG에 반영한다. 쪽 여백은 본문 글자의 안쪽 여백으로 보인다.

글꼴은 시스템에 있는 한글 폰트를 `font-family`로 지정한다. 폰트 파일을 저장소에 넣지 않는다.

## 화면이 문서를 보여 준다

화면이 문서를 보여 준다. 쪽 여백, 그림, 표 격자, 파일에 있는 줄 위치가 이 화면의 필수다. 쪽 여백은 위 WP-03 문장 그대로다. 다음 화면은 [D16](days/D16.md) 그림, [D17](days/D17.md) 표 격자, [D18](days/D18.md) 줄 위치다. 서식 수정 명령과 섞지 않는다. D07 다운로드를 이 화면 작업으로 바꾸지 않는다.

D16에 그림을 그린다. 본문 `pic`와 manifest의 BinData를 연결해 화면에 그린다. 크기는 파일의 현재 크기다. `curSz`가 있으면 그 크기고, 없으면 `orgSz`다. 파일에 없는 그림 요소는 만들지 않는다. 이미지 교체 명령은 이 그리기 다음이다.

D17에 표 격자를 그린다. `tbl`의 행과 칸, `cellAddr`, `cellSpan`, `cellSz`, 칸 글자, 칸 안 그림이 화면에 보인다. `cellAddr`, `cellSpan`, `cellSz`, `subList`는 구현 문서의 관찰이다. D08은 칸 글자를 바꾸는 수정으로 남는다. 격자를 그리는 일은 그 글자 교체와 다른 화면 작업이다. 칸 안 문단을 바깥 본문 문단 글자에 펼쳐 넣지 않고 본문 문단 목록에서 빼 두는 현재 읽기 규칙은 유지한다. 화면에서만 표로 보인다.

D18의 줄 위치. 문단에 `linesegarray`가 있으면 화면 줄은 그 줄의 `vertpos`, `horzpos`, `horzsize`, `textpos`, `baseline`을 쓴다. `linesegarray`는 OWPML이 아니라 한글 레이아웃 캐시다. 16px/8px, 너비 710px 근사치는 그 캐시가 없을 때만 쓰는 대체다. D05 기록은 그때 한 근사치로 남는다. 수정 때 `linesegarray`를 지울지 남길지는 D09에서 한글로 확인하기 전에 정하지 않는다. 없는 `linesegarray`는 새로 계산해 넣지 않는다. 화면은 파일에 있는 줄 위치를 쓴다.
