# 테스트 기준

테스트는 매번 같은 코퍼스를 다시 돈다. 샘플 정의는 [corpus.md](corpus.md)에 있다.

## 레벨

1. **패키지.** ZIP 엔트리 이름, 크기, 압축 방식, `mimetype` 위치.
2. **XML.** well-formed, 네임스페이스, 바꾸지 않은 요소의 존재.
3. **모델.** 문단, 런 개수, 표 칸, 원문.
4. **화면.** 데모 순서와 선택 결과 JSON.
5. **편집.** 대상 외 텍스트 해시가 같은지.
6. **한컴.** 열기, 편집 가능, 저장, 다시 열기. D09부터 기록.
7. **회귀.** 이후 날에도 D01 fixture 테스트를 깨지 않는다.

## 자동

D01부터 Vitest를 둔다.

- `pnpm test`가 하루의 자동 항목을 모두 실행한다.
- 패키지 테스트는 브라우저 없이 `packages/hwpx`, `packages/commands`에서 돈다.
- 화면 테스트는 선택 JSON과 표시 텍스트처럼 관찰 가능한 값만 고정한다. 픽셀 일치는 D05 이후에 기준 이미지를 하나 둘 수 있다. 그 전엔 필수 조건으로 두지 않는다.

최소 fixture는 테스트 코드가 ZIP으로 직접 만든다. 한컴이 없어도 D01–D08의 자동 테스트가 돈다. 한컴이 만든 파일은 `corpus/hancom/`에만 두고, 비밀 문서는 커밋하지 않는다.

## 수동 데모

하루 파일의 데모 순서를 저장소의 샘플 또는 로컬 T01으로 한 번 실행한다. 결과 문장을 그날 파일의 기록란에 남긴다.

## 릴리스를 막는 조건

- 결과 ZIP이 열리지 않음
- 한컴 한글에서 열리지 않음
- 수정하지 않은 문단, 이미지, 엔트리가 사라짐
- 승인하지 않은 텍스트가 바뀜
- 미지원 요소를 지우고 저장함
- 원본 파일을 덮어씀
- 검증에 실패한 명령을 적용함

이 중 하나라도 보이면 그날의 기능을 완료로 적지 않는다.
