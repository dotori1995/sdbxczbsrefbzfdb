# 코퍼스

한컴으로 만든 파일은 `corpus/hancom/`에 둔다. 이 디렉터리는 gitignore되어 있다. 샘플 본문은 커밋하지 않는다.

자동 테스트용 ZIP은 한컴 없이 `packages/hwpx`가 만든다.

## T01

한글에서 새 문서를 만들고 문단을 두 개 입력한 뒤 HWPX로 저장한다. 본문은 공개해도 되는 문장만 쓴다.

예: `첫번째 문단이다.` / `두번째 문단이다.`

파일 이름: `corpus/hancom/T01.hwpx`

## T02

한 문단에 굵게 런과 일반 런이 같이 있다. 승인해도 적용하지 않고 `MIXED_RUNS`로 거절한다.

## T03

2행 2열이다. 칸마다 문장이 다르다. 자동 fixture는 D08에서 만든다.

| 1행 2열 | 둘째칸 |
| 2행 1열 | 셋째칸 |
